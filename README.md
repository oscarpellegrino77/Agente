# Agente de IA

![Agente de IA](portada.jpg)

App web instalable (PWA) de un agente autónomo. Usa tu clave de OpenRouter: busca en internet, lee páginas, crea archivos descargables y puede hablar en voz alta. Mantiene la pantalla encendida mientras trabaja (Wake Lock).

## Instalar
1. Activá GitHub Pages en este repositorio (Settings, Pages, rama `main`, carpeta raíz).
2. Abrí la dirección de la página en Chrome del Android.
3. Tocá **Instalar en el teléfono**, o el menú de Chrome y **Agregar a la pantalla principal**.

## Voz y candado
Al abrir pide nombre y contraseña. Con el micrófono (o “Escuchar siempre”) solo obedece órdenes que empiezan con 704, por ejemplo “704, buscá tal cosa”. “704, para” detiene la tarea. El candado es un cerrojo de uso personal, no seguridad fuerte.

## Límites
No ejecuta JavaScript en las páginas que visita, no inicia sesión en sitios ni llena formularios, y necesita la app abierta con la pantalla encendida para trabajar.
